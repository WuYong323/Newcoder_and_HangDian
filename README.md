# 暑假多校补题记录

记录 2026 年暑假 **牛客多校** 与 **杭电多校** 的补题过程：AC 代码 + 题解笔记。

## 目录

- [牛客多校](自己的总结与自己的题解/2026牛客多校/) — 牛客暑期多校训练营
- [杭电多校](自己的总结与自己的题解/2026杭电多校/) — HDU 暑期多校训练营
- [模板](./模板/) — 常用竞赛模板与题解笔记模板

## 组织方式

```
牛客多校/
  第01场/
    README.md      # 本场题目索引
    A/
      sol.cpp      # AC 代码
      note.md      # 题解笔记
    B/
      ...
```

## 补题流程

1. 从 `模板/template.cpp` 复制一份到题目目录，重命名为 `sol.cpp`。
2. 从 `模板/题解模板.md` 复制笔记到 `note.md`，边补边填思路和坑点。
3. AC 后更新对应场次的 `README.md` 索引状态。
